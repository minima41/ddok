# 사용 방법

1. APK 설치 후 앱을 실행합니다.
2. 접근성 설정에서 `7시 똑닥 매크로` 서비스를 켭니다.
3. 정확한 알람 권한과 알림 권한을 허용합니다.
4. 예약 대상을 `이도아` 또는 `이도연` 중에서 선택합니다.
5. 원하는 시간을 1~5순위로 지정합니다. 기본값은 `09:10 → 09:20 → 09:30`입니다.
6. `매일 실행 등록`을 누릅니다.
7. 07:00 예약 오픈 시 앱이 저장된 순서대로 똑닥 화면을 조작하고, 앞 시간이 마감되면 다음 우선순위를 시도합니다.

실사용 전에는 `지금 테스트`로 클릭 경로가 현재 똑닥 화면과 일치하는지 확인하세요. 테스트 모드는 최종 예약 버튼 직전에 멈춥니다.
